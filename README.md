# Bubble Pop Game (JavaScript / HTML5 / CSS3)

An interactive browser game where players pop randomly generated colorful bubbles to increase their score[cite: 5, 6].

## Features

- **Dynamic Spawning:** Automatically spawns a new bubble every second at random coordinates across the viewport.
- **Random Color Palette:** Generates custom hexadecimal colors on each spawn.
- **Interactive Animations:** Bubbles enlarge smoothly on mouse hover using CSS transforms.
- **Live Score Tracking:** Tracks popped bubbles and updates the score counter in real time[cite: 5, 6].
